# Clinic X – Complete Clinic Management System

Based on **CliniSYS GP** User’s Guide, Brochure and Presentation.

## New / Enhanced Features

- **Animated login page** with moving background + Clinic X logo
- **Goods Return** to supplier (with stock reduction)
- **Stock Adjustment** screen (stock take / correction)
- **MOH Psychotropic Report** (Prescription Register for Psychotropic Substances)
- Inventory: Stock Master, Supplier, Purchase Order, Goods Receive
- Corporate Invoicing
- Appointments
- Reports (Sales, Inventory, Prescription, Psychotropic)
- Full patient flow (Registration → Queue → Consultation → Dispensary → Payment)

## How to Run

```bash
cd ClinicX-Complete
node server.js
```

Open: **http://localhost:3000**
